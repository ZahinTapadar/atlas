How it works

It tracks. Claude coaches.

ATLAS does one thing well: an honest record of your day. The judgment happens later, on a schedule you choose.

01

Track

A native, event-driven tracker follows apps, windows, browser tabs, idle time and sleep. No polling loops, no screenshots.

02

Understand

A local classifier sorts time into coding, research, reading, video, gaming, social and more, and labels uncertain time as uncertain instead of guessing.

03

Check in

A scheduled Claude task reads ATLAS, your calendar and your daily briefing, then tells you plainly whether you're on track and what to do next.

Privacy

Your day stays on your Mac.

ATLAS watches highly personal behavior, so privacy is built into its design rather than added on later.

  • Local-first storageA SQLite database in your Library. Export it or delete it at any time.
  • No keylogging, no screenshotsIt never reads keystrokes, form fields, passwords, documents or screen contents.
  • Exclusions and private modeExcluded apps and sites are stored as timing only, with no names, titles or URLs.
  • Summaries, not streamsClaude sees compact summaries on demand, never a live feed or your full browsing history.
  • Explicit permissionsEach permission is requested openly and can be skipped. ATLAS still works without them.
  • Your Claude plan, not API billingAnalyses run through Claude Code with your subscription. ATLAS never falls back to an API key.
Built for Claude

An MCP server for your own activity.

ATLAS ships with atlasctl, a command-line tool that is also an MCP server. Any Claude session or scheduled task can ask what you actually did, and write its feedback back into the app.

# Registered by the installer
claude mcp add atlas -- atlasctl mcp

# Tools
get_activity_summary  time, apps, focus
get_current_activity  right now
get_recent_checkins   earlier feedback
record_checkin        save a verdict

# Or from a terminal
atlasctl today
atlasctl summary --from -3h --json
Install

Build it in a minute.

Requires macOS 14+ and Xcode 16 or later. The script builds, signs with your Apple Development certificate when available, installs to ~/Applications, and registers the MCP server.

git clone https://github.com/ZahinTapadar/atlas.git
cd atlas
./scripts/build-app.sh
open ~/Applications/ATLAS.app
